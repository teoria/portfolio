I'm using a really nice workflow with Claude for data projects on Atlassian:

1. Brainstorm with Claude (Opus) to specify what needs to be done, using the Slack MCP to find the team's past decisions and related problems.
2. Create Jira tasks via MCP.
3. Read the task in another session via MCP.
4. Implement (commit, PR, merge).
5. Update the Jira status and add a comment with evidence via MCP.
6. Write the current state of what was built to Confluence.

What's new here? The history of business decisions and code, linked in Confluence. Accessible to stakeholders (non-devs) and to your AI.

Get the idea? You can do this with any task tracker.
