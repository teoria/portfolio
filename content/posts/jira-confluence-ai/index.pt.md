Tô usando um fluxo bem legal com o Claude para projetos de dados usando Atlassian:

1. Brainstorm no Claude com Opus para especificar o que precisa ser feito (MCP do Slack para buscar decisões passadas do time e problemas relacionados).
2. Crio tasks no Jira usando MCP.
3. Leio a task numa outra sessão usando MCP.
4. Implemento (commit, PR, merge).
5. Atualizo o status e o comentário (evidências) no Jira usando MCP.
6. O estado atual do que foi construído é escrito no Confluence.

Qual a novidade aí? Histórico de decisões de negócio e código linkados no Confluence! Acessível para stakeholders (não devs) e para sua IA.

Sacou a ideia? Dá pra fazer isso com qualquer sistema de tarefas.
