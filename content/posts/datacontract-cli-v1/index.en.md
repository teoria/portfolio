DataContract-cli v1.0 is out: the tool everyone in data needs and most people still don't know about!

Great to see this project grow. It's essential for doing data governance well. If you've never heard of data contracts: [datacontract.com](https://datacontract.com).

It's not just about documenting what resources exist. It's about understanding the impact of changes. Shift-left for pipeline errors!

I'm talking about blocking, still in CI/CD, the release that would change a contract's schema and break pipelines and dashboards. The error never happened. The broken version never reached prod.

See the difference?
